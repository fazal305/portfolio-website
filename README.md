# Fazal Abbas Portfolio Website

A responsive personal portfolio for Fazal Abbas, built to present frontend projects, learning progress, technical skills, and contact details in one polished Firebase-hosted website.

## Live Website

https://fazal-abbas-portfolio.web.app/

## Project Overview

This portfolio is designed as a professional home base for my web development work. It highlights real projects with screenshots, GitHub links, live demos, skills, and a contact section for internships, junior frontend opportunities, freelance work, and collaboration.

The site is intentionally lightweight: no framework build process, no bundler, and no backend requirement. It can be edited quickly and deployed directly with Firebase Hosting.

## Features

- Futuristic dark portfolio interface
- Responsive layout for desktop, tablet, and mobile
- Hero section with animated role text
- Project gallery with category filters
- Real project screenshots from my repositories
- About section with learning-focused profile
- Skill groups for frontend, scripting, tools, and concepts
- Animated counters and scroll reveal effects
- Copy email button and contact form validation
- Custom 404 page
- Firebase Hosting configuration

## Run Locally

Open `index.html` directly in a browser, or use a simple local server:

```powershell
python -m http.server 5500
```

Then visit:

```text
http://localhost:5500
```

## Deploy

This project is configured for Firebase Hosting.

```powershell
firebase deploy
```
